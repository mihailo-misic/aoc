## Getting Started

1. Go to: https://adventofcode.com
2. Log in
3. Copy the `session` cookie value
4. Set it as a `AOC_SESSION` environment variable:  
   ```bash
   export AOC_SESSION="<SESSION_COOKIE_VALUE>"
   ```
5. Go to the project's root dir
6. Start a new day via the startDay script:  
   ```bash
   bash ./scripts/startDay.sh
   ```
